# Calibração com os posts do Dollynho

- `dollynho/AAAA-MM-DD_HHMM_<tf>.md` — texto do post dele (transcrito do print que o Augustus manda) + o que o gráfico dele mostra.
- `placar.md` — para cada fechamento: o que o nosso Log disse x o que ele disse (leituras, alvos, stop, postura), e se bateu.
- Regra: só mudar código/skill quando a mesma diferença aparecer 2 ou 3 vezes.

## Objetivo: autonomia (definido em 11/11/2026)
O Log é sempre escrito ANTES de ver o post do Dollynho (às cegas), com postura própria pelo método. O post dele só serve depois, como gabarito.
A cada post comparado, registrar em placar.md, por fechamento:
- **Direção:** mesma tese (alta/queda/fora)? sim/não
- **Ação:** mesma ação (entra/mantém/parcial/fecha/fora)? sim/não
- **Stop:** mesma média de stop? sim/não
- **Alvo:** mesmo 🎯 principal? sim/não
- **Leitura:** fatos citados por ele que o Log também citou (ex.: 3 de 4)
Meta para considerar o método "rodando sozinho": ação e stop iguais em ≥ 80% dos últimos 30 fechamentos comparados, sem nenhum trade aberto/fechado na mão contrária à dele. Até lá, cada divergência repetida 2-3x vira regra em cronologia_trades.md.
Limites conhecidos: linhas desenhadas à mão (Linha Verde/Amarela) e decisões discricionárias dele não são reproduzíveis só com dados; resultado financeiro não é garantido mesmo com leitura igual.
